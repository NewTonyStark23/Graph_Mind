## 🚀 How to Use

### 1. Install and Run
```bash
npm install
npm run dev
```

### 2. Analyze a Local File
- Click "🔬 Analyze File"
- Drag-and-drop a `.safetensors` or `.gguf` file
- Wait for extraction (progress bar)
- Explore 6 tabs: Overview, Tensors, Statistics, SVD, Advanced, Brain Map

### 3. Browse HuggingFace Models
- Click "🌐 Browse HF Models"
- Search by name or architecture
- View real model metadata
- Download models for analysis

### 4. Compare Two Models
- Extract two models
- Click "🔀 Compare Models"
- View compatibility score
- Get merge recommendations

### 5. Export Results
- Click "💾 Export Advanced Graphify"
- Downloads JSON with all extracted data
- Includes tensors, stats, SVD, fingerprints
